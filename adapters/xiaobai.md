# 小白音乐

- ID：`xiaobai`
- 版本：`0.1.0`
- 作者：[Miaoyww](https://github.com/Miaoyww)
- 许可证：MIT
- 仓库：https://github.com/Miaoyww/nons-adapter-xiaobai
- 状态：可用

按网易云、QQ音乐、酷狗和酷我的歌曲 ID 提供备用音源，不参与搜索；可用性取决于上游与歌曲。

## 支持平台

- `netease`
- `qqmusic`
- `kugou`
- `kuwo`

## 权限

- HTTP：`music.90svip.cn`
- HTTP：`*.music.126.net`
- HTTP：`*.music.163.com`
- HTTP：`*.tc.qq.com`
- HTTP：`*.stream.qqmusic.qq.com`
- HTTP：`*.kugou.com`
- HTTP：`*.kugou.net`
- HTTP：`*.kuwo.cn`

## 兼容性

- 契约版本：`1`
