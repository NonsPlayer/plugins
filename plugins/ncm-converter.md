# NCM 格式转换

- ID：`ncm-converter`
- 版本：`2.0.0`
- 作者：[NonsPlayer](https://github.com/Miaoyww)
- 许可证：GPL-3.0-only
- 仓库：https://github.com/Miaoyww/ncm-converter
- 状态：可用
- 标签：`tool`

批量将本地 NCM 恢复为 MP3 或 FLAC，保留歌曲信息，默认保存到原文件目录。

## 权限

- `ui`
- `files:selected`

- 插件 API：`^3.0.0`
- UI API：`^3.0.0`
